morning-brief Privacy Policy

Last updated: October 2026

What the app does

morning-brief is a personal tool run by its owner. It generates a daily summary email for the owner only.

Google user data accessed

With the owner's permission, the app requests read-only access to the owner's Google Calendar (calendar.readonly) and Google Tasks (tasks.readonly). It reads event titles, times, birthdays, and task titles and due dates.

How the data is used

The data is used only to build the daily summary email sent to the owner. It is not used for advertising, analytics, or any other purpose.

Storage and sharing

The app does not store Google user data beyond the moment the summary is generated. Data is not sold, shared with, or transferred to any third party. No humans read the data other than the owner.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
